☕ Maven 完整教程

Maven 是一个基于项目对象模型 (POM) 的 Java 项目构建和依赖管理工具。本教程涵盖安装、项目创建以及常用命令。

1. 安装 Maven

从 Apache Maven 官网 下载二进制包，解压后将 bin 目录添加到环境变量 PATH。通过以下命令验证安装：

mvn -v

2. 创建项目

使用 Archetype 快速生成一个 Java 项目：

mvn archetype:generate -DgroupId=com.example -DartifactId=demo -DarchetypeArtifactId=maven-archetype-quickstart -DinteractiveMode=false

3. 常用命令

  • mvn compile 编译源码
  • mvn test 运行测试
  • mvn package 打包项目
  • mvn clean 清理构建输出
