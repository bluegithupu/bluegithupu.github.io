1. 什么是NPM？

NPM（Node Package Manager）是 Node.js 的包管理器，也是世界上最大的软件注册表。它包含三个组件：

  • 网站： 用于发现包、设置配置文件和管理npm体验的其他方面
  • 命令行界面 (CLI)： 在终端中运行，开发者通过它与npm进行交互
  • 注册表： 一个大型公共JavaScript软件数据库及其周围的元信息

NPM的主要功能：

  • 安装和管理项目依赖
  • 运行脚本和任务
  • 发布和分享代码包
  • 版本控制和语义化版本

2. 安装和设置

2.1 安装 Node.js 和 NPM

NPM 随 Node.js 一起安装。访问 nodejs.org 下载并安装最新版本。

2.2 验证安装

# 检查 Node.js 版本
node --version

# 检查 NPM 版本
npm --version

2.3 配置 NPM

# 设置用户信息
npm config set init-author-name "你的名字"
npm config set init-author-email "your-email@example.com"
npm config set init-license "MIT"

# 查看当前配置
npm config list

3. 基本概念

3.1 包（Package）

包是一个包含 package.json 文件的文件夹或文件。

3.2 模块（Module）

模块是能被 Node.js 的 require() 函数加载的任何东西。

3.3 依赖（Dependencies）

  • dependencies： 生产环境需要的包
  • devDependencies： 只在开发环境需要的包
  • peerDependencies： 对等依赖
  • optionalDependencies： 可选依赖

4. package.json 详解

package.json 是项目的清单文件，包含项目的元数据和依赖信息。

4.1 创建 package.json

# 交互式创建
npm init

# 使用默认值快速创建
npm init -y

4.2 package.json 结构示例

{
  "name": "my-awesome-project",
  "version": "1.0.0",
  "description": "一个很棒的项目",
  "main": "index.js",
  "scripts": {
    "start": "node index.js",
    "test": "jest",
    "build": "webpack --mode production",
    "dev": "nodemon index.js"
  },
  "keywords": ["javascript", "nodejs", "npm"],
  "author": "你的名字 <your-email@example.com>",
  "license": "MIT",
  "dependencies": {
    "express": "^4.18.2",
    "lodash": "^4.17.21"
  },
  "devDependencies": {
    "jest": "^29.0.0",
    "nodemon": "^2.0.20"
  },
  "engines": {
    "node": ">=14.0.0",
    "npm": ">=6.0.0"
  }
}

4.3 重要字段说明

字段 描述 必需
name 包的名称 是
version 包的版本 是
description 包的描述 否
main 入口文件 否
scripts 可运行的脚本 否
dependencies 生产依赖 否
devDependencies 开发依赖 否

5. 基础命令

5.1 安装包

# 安装单个包
npm install express

# 安装多个包
npm install express lodash moment

# 安装并保存到 dependencies
npm install --save express

# 安装并保存到 devDependencies
npm install --save-dev jest

# 全局安装
npm install -g nodemon

# 安装特定版本
npm install express@4.18.2

5.2 卸载包

# 卸载包
npm uninstall express

# 卸载并从 package.json 中移除
npm uninstall --save express

# 全局卸载
npm uninstall -g nodemon

5.3 更新包

# 更新所有包
npm update

# 更新特定包
npm update express

# 检查过时的包
npm outdated

5.4 查看包信息

# 查看已安装的包
npm list

# 查看全局安装的包
npm list -g

# 查看包的详细信息
npm info express

# 查看包的版本历史
npm view express versions --json

6. 依赖管理

6.1 版本控制

NPM 使用语义化版本（SemVer）：主版本.次版本.修订版本

符号 含义 示例 匹配版本
^ 兼容版本 ^1.2.3 ≥1.2.3 <2.0.0
~ 近似版本 ~1.2.3 ≥1.2.3 <1.3.0
* 任意版本 * 任何版本
无符号 精确版本 1.2.3 1.2.3

6.2 package-lock.json

重要： package-lock.json 文件锁定依赖的确切版本，确保团队成员安装相同版本的依赖。应该提交到版本控制系统中。

6.3 清理和修复

# 清理 node_modules
rm -rf node_modules package-lock.json

# 重新安装
npm install

# 审计安全漏洞
npm audit

# 自动修复安全问题
npm audit fix

7. NPM Scripts

NPM Scripts 是在 package.json 中定义的可执行脚本。

7.1 基本用法

{
  "scripts": {
    "start": "node server.js",
    "dev": "nodemon server.js",
    "test": "jest",
    "build": "webpack --mode production",
    "lint": "eslint src/",
    "format": "prettier --write src/"
  }
}

7.2 运行脚本

# 运行 start 脚本
npm start

# 运行其他脚本
npm run dev
npm run test
npm run build

7.3 脚本钩子

{
  "scripts": {
    "prebuild": "npm run lint",
    "build": "webpack",
    "postbuild": "npm run test"
  }
}

7.4 传递参数

# 在脚本中
"test": "jest"

# 运行时传递参数
npm run test -- --watch

8. 发布包

8.1 准备发布

# 创建 npm 账户
npm adduser

# 登录
npm login

# 检查登录状态
npm whoami

8.2 发布流程

# 检查包名是否可用
npm search your-package-name

# 发布包
npm publish

# 发布预发布版本
npm publish --tag beta
注意：
  • 包名必须唯一
  • 版本号不能重复
  • 确保 .npmignore 文件正确配置

8.3 版本管理

# 更新版本号
npm version patch   # 1.0.0 -> 1.0.1
npm version minor   # 1.0.0 -> 1.1.0
npm version major   # 1.0.0 -> 2.0.0

# 带标签的版本
npm version prerelease --preid=alpha  # 1.0.0 -> 1.0.1-alpha.0

9. 高级特性

9.1 NPM 配置

# 查看所有配置
npm config list -l

# 设置注册源
npm config set registry https://registry.npmjs.org/

# 使用淘宝镜像
npm config set registry https://registry.npmmirror.com/

# 设置代理
npm config set proxy http://proxy.company.com:8080

9.2 .npmrc 文件

# 项目级别 (.npmrc)
registry=https://registry.npmmirror.com/
save-exact=true
init-license=MIT

9.3 npm link

用于本地开发时链接包：

# 在要链接的包目录中
npm link

# 在使用包的项目中
npm link package-name

9.4 工作空间（Workspaces）

管理单体仓库中的多个包：

{
  "workspaces": [
    "packages/*",
    "apps/*"
  ]
}

10. 最佳实践

10.1 安全性

  • 定期运行 npm audit 检查安全漏洞
  • 使用 npm ci 在生产环境中安装依赖
  • 避免使用 sudo 运行 npm 命令

10.2 性能优化

# 使用 npm ci 替代 npm install（在 CI/CD 中）
npm ci

# 清理缓存
npm cache clean --force

# 设置缓存目录
npm config set cache /path/to/cache

10.3 项目组织

  • 合理使用 dependencies 和 devDependencies
  • 保持 package-lock.json 在版本控制中
  • 使用语义化版本控制
  • 编写有意义的脚本命令

10.4 常用工具推荐

类别 工具 用途
代码质量 ESLint, Prettier 代码检查和格式化
测试 Jest, Mocha 单元测试
构建 Webpack, Rollup 模块打包
开发 Nodemon, Live Server 开发服务器
