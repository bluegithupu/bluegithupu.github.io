系统概览

OpenCode Tools 是一个为 AI 代码助手设计的工具集，提供了文件操作、代码搜索、命令执行等核心功能。每个工具都遵循统一的接口设计，支持权限控制和历史记录。

工具架构

所有工具都实现了 BaseTool 接口，提供统一的调用方式和响应格式。

type BaseTool interface { Info() ToolInfo Run(ctx context.Context, params ToolCall) (ToolResponse, error) } type ToolInfo struct { Name string Description string Parameters map[string]any Required []string } type ToolResponse struct { Type toolResponseType Content string Metadata string IsError bool }

文件操作工具

文件操作工具提供了完整的文件读写、编辑和诊断功能。

View Tool

文件查看工具 - 读取和显示文件内容

功能特性

行号显示

自动为文件内容添加行号，便于定位和引用

分页读取

支持偏移量和限制参数，处理大文件

文件类型检测

自动识别图片文件并提供相应提示

LSP 集成

自动获取语言服务器诊断信息

参数说明

参数名 类型 必需 说明
file_path string 是 要读取的文件路径
offset integer 否 起始行号（从0开始）
limit integer 否 读取行数（默认2000）

使用示例

{ "file_path": "/path/to/file.go", "offset": 0, "limit": 100 }

使用建议

  • 在编辑文件前先使用 View 工具查看内容
  • 对于大文件，使用 offset 参数分段查看
  • 结合 Grep 工具先找到相关文件再查看

Edit Tool

文件编辑工具 - 精确的文本替换和内容修改

功能特性

精确替换

基于字符串匹配的精确内容替换

创建文件

支持创建新文件（old_string 为空）

删除内容

支持删除内容（new_string 为空）

安全检查

确保唯一匹配，防止意外修改

参数说明

参数名 类型 必需 说明
file_path string 是 要编辑的文件路径（必须是绝对路径）
old_string string 是 要替换的文本（必须唯一匹配）
new_string string 是 替换后的文本

重要注意事项

  • 唯一性要求：old_string 必须在文件中唯一匹配
  • 上下文要求：包含足够的上下文（3-5行）确保唯一性
  • 精确匹配：包括所有空白字符和缩进
  • 预读要求：编辑前必须先用 View 工具读取文件

使用示例

// 替换函数内容 { "file_path": "/path/to/file.go", "old_string": "func example() {\n // old implementation\n return nil\n}", "new_string": "func example() {\n // new implementation\n return result\n}" } // 创建新文件 { "file_path": "/path/to/new_file.go", "old_string": "", "new_string": "package main\n\nfunc main() {\n fmt.Println(\"Hello\")\n}" }

Write Tool

文件写入工具 - 创建或完全重写文件

功能特性

完整重写

完全替换文件内容或创建新文件

目录创建

自动创建必要的父目录

冲突检测

检测文件是否在读取后被修改

差异生成

自动生成修改前后的差异对比

参数说明

参数名 类型 必需 说明
file_path string 是 要写入的文件路径
content string 是 要写入的完整内容

适用场景

  • 创建全新的文件
  • 完全重写现有文件
  • 生成配置文件或模板
  • 大幅度修改时比 Edit 工具更适合

Patch Tool

补丁工具 - 应用 Git 风格的补丁文件

功能特性

Git 补丁

支持标准 Git diff 格式的补丁

多文件支持

一次性应用多个文件的修改

权限控制

每个文件修改都需要权限确认

统计信息

提供添加和删除行数的统计

参数说明

参数名 类型 必需 说明
patch_text string 是 Git diff 格式的补丁内容

Diagnostics Tool

诊断工具 - 获取语言服务器的诊断信息

功能特性

LSP 集成

与语言服务器协议集成

实时诊断

获取语法错误、警告等信息

多语言支持

支持各种编程语言的诊断

严重性分类

按错误、警告、信息分类显示

参数说明

参数名 类型 必需 说明
file_path string 是 要诊断的文件路径

搜索工具

搜索工具提供了强大的文件查找和内容搜索功能。

LS Tool

目录列表工具 - 显示目录结构

功能特性

树形结构

以层次化树形结构显示目录内容

智能过滤

自动跳过隐藏文件和常见的构建目录

自定义忽略

支持自定义忽略模式

限制保护

限制最大文件数防止输出过多

参数说明

参数名 类型 必需 说明
path string 是 要列出的目录路径
ignore array 否 要忽略的 glob 模式列表

使用示例

{ "path": "/project/src", "ignore": ["*.test.js", "temp*"] }

Glob Tool

文件匹配工具 - 按模式查找文件

功能特性

模式匹配

支持标准 glob 模式语法

递归搜索

支持 ** 进行递归目录搜索

时间排序

按修改时间排序，最新文件优先

高性能

优先使用 ripgrep 提升搜索性能

Glob 模式语法

模式 说明 示例
* 匹配任意字符（不包括路径分隔符） *.js
** 递归匹配任意路径 **/*.go
? 匹配单个字符 test?.js
[...] 匹配字符集合 *.[ch]
{...} 匹配多个选项 *.{js,ts}

使用示例

// 查找所有 Go 文件 { "pattern": "**/*.go", "path": "/project" } // 查找测试文件 { "pattern": "**/*_test.{go,js}", "path": "/project/src" }

Grep Tool

内容搜索工具 - 在文件中搜索文本模式

功能特性

正则表达式

支持强大的正则表达式搜索

字面量搜索

支持字面量文本搜索模式

文件过滤

支持按文件类型过滤搜索范围

上下文显示

显示匹配行及其行号

参数说明

参数名 类型 必需 说明
pattern string 是 搜索的正则表达式模式
path string 否 搜索的起始目录
include string 否 包含的文件模式
literal_text boolean 否 是否按字面量搜索

使用示例

// 搜索函数定义 { "pattern": "func\\s+\\w+", "include": "*.go", "literal_text": false } // 字面量搜索 { "pattern": "fmt.Println(", "include": "*.go", "literal_text": true }

搜索技巧

  • 使用 literal_text=true 搜索包含特殊字符的文本
  • 结合 include 参数限制搜索范围提升性能
  • 先用 Glob 找到相关文件再用 Grep 搜索内容

Sourcegraph Tool

代码搜索工具 - 全局代码搜索服务

功能特性

全局搜索

跨项目和仓库的代码搜索

语义搜索

理解代码语义的智能搜索

上下文窗口

可配置的搜索结果上下文

结果限制

可控制的搜索结果数量

参数说明

参数名 类型 必需 说明
query string 是 搜索查询字符串
count integer 否 返回结果数量
context_window integer 否 上下文窗口大小
timeout integer 否 搜索超时时间

执行工具

执行工具提供了命令行执行和持久化 Shell 会话功能。

Bash Tool

命令执行工具 - 在持久化 Shell 会话中执行命令

功能特性

持久化会话

所有命令共享同一个 Shell 会话，环境变量和目录状态保持

安全控制

禁止危险命令，安全命令无需权限确认

超时保护

可配置的命令执行超时时间

输出管理

自动截断过长输出，防止响应过大

参数说明

参数名 类型 必需 说明
command string 是 要执行的 bash 命令
timeout integer 否 超时时间（毫秒，最大600000）

禁止的命令

以下命令被禁止使用以确保安全：

alias, curl, curlie, wget, axel, aria2c, nc, telnet, lynx, w3m, links, httpie, xh, http-prompt, chrome, firefox, safari

安全只读命令

以下命令无需权限确认即可执行：

ls, echo, pwd, date, whoami, git status, git log, git diff, go version, go help 等

Git 提交流程

工具内置了完整的 Git 提交工作流程：

  1. 运行 git status 查看未跟踪文件
  2. 运行 git diff 查看变更
  3. 运行 git log 了解提交历史风格
  4. 分析变更并生成提交信息
  5. 执行提交并添加 AI 生成标识

使用示例

// 基本命令执行 { "command": "ls -la", "timeout": 5000 } // Git 操作 { "command": "git status" } // 构建项目 { "command": "go build ./...", "timeout": 30000 }

最佳实践

  • 避免使用 find、grep 等搜索命令，使用专门的搜索工具
  • 避免使用 cat、head、tail 等读取命令，使用 View 工具
  • 使用分号或 && 连接多个命令而不是换行
  • 尽量使用绝对路径避免频繁 cd

Persistent Shell

持久化 Shell - 底层 Shell 会话管理

功能特性

会话保持

维护长期运行的 Shell 进程

状态持久化

环境变量、工作目录等状态保持

并发安全

支持并发命令执行的安全管理

进程管理

自动清理子进程，防止僵尸进程

核心方法

方法 说明 返回值
Exec() 执行命令 stdout, stderr, exitCode, interrupted, error
Close() 关闭 Shell 会话 void
killChildren() 终止所有子进程 void
type PersistentShell struct { cmd *exec.Cmd stdin *os.File isAlive bool cwd string mu sync.Mutex commandQueue chan *commandExecution }

实用工具

实用工具提供了网络请求和其他辅助功能。

Fetch Tool

网络请求工具 - 获取网络资源

功能特性

多格式支持

支持 HTML、文本、Markdown 等格式

内容转换

自动将 HTML 转换为 Markdown

权限控制

网络请求需要权限确认

超时保护

可配置的请求超时时间

参数说明

参数名 类型 必需 说明
url string 是 要请求的 URL
format string 是 响应格式 (html, text, markdown)
timeout integer 否 超时时间（秒）

支持的格式

  • html - 返回原始 HTML 内容
  • text - 提取纯文本内容
  • markdown - 转换为 Markdown 格式

使用示例

// 获取网页并转换为 Markdown { "url": "https://example.com/api/docs", "format": "markdown", "timeout": 30 } // 获取纯文本内容 { "url": "https://api.example.com/status", "format": "text" }

常见工作流程

1. 新功能开发

1. LS 工具浏览项目结构 2. Glob 工具找到相关文件 3. View 工具查看现有代码 4. Edit/Write 工具实现功能 5. Diagnostics 检查语法 6. Bash 工具运行测试

2. Bug 修复

1. Grep 工具搜索错误信息 2. View 工具查看问题代码 3. Edit 工具进行精确修改 4. Diagnostics 验证修复 5. Bash 工具测试修复效果

3. 代码重构

1. Grep 工具找到所有相关代码 2. View 工具理解现有实现 3. Write 工具重写核心文件 4. Edit 工具调整相关文件 5. Patch 工具批量更新 6. 全面测试验证

注意事项

  • 始终在编辑前使用 View 工具读取文件
  • Edit 工具要求 old_string 在文件中唯一匹配
  • Bash 工具有安全限制，某些命令被禁止
  • 所有文件操作都会记录历史和生成差异
  • 权限系统会拦截潜在危险操作

性能优化建议

  • 使用 include 参数限制搜索范围
  • 优先使用 ripgrep 加速搜索
  • 避免在大目录上使用 LS 工具
  • 合理设置超时时间
  • 批量操作时使用 Patch 工具

总结

OpenCode Tools 提供了一套完整的 AI 代码助手工具集，涵盖了文件操作、搜索、执行和实用功能。通过合理使用这些工具，可以高效地进行代码开发、调试和维护工作。

每个工具都经过精心设计，具有统一的接口、完善的权限控制和详细的错误处理。结合最佳实践，这些工具能够为 AI 代码助手提供强大而安全的操作能力。
